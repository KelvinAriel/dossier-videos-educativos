# Dossier Digital de Videos Educativos

Sitio web académico de Telecomunicaciones Educativas I, grupo GT-01, Universidad de El Salvador, ciclo II-2026.

## Contenido

- Inicio y presentación del proyecto.
- Unidades 1, 2, 3, 4 y 6.
- Rotación de roles.
- Reflexión final.

## Tecnologías

HTML5, CSS3 y JavaScript, sin dependencias externas. El sitio es responsive y puede publicarse directamente con GitHub Pages.

Los videos y documentos se mantienen en Google Drive. El acceso depende de los permisos configurados en cada archivo.
